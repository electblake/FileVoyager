# Qt Framework

> Qt is a cross-platform application development framework for desktop, embedded,
  and mobile platforms. Qt enables developers to create applications that run on
  various software and hardware platforms with little or no change in the
  underlying codebase, while maintaining native capabilities and speed.

## Essential References

- [All Qt Modules](https://doc.qt.io/qt/qtmodules.html):
  Complete list of Qt modules organized by category.
- [All Qt Classes](https://doc.qt.io/qt/classes.html): Alphabetical index of all
  Qt classes.
- [Qt Core Module](https://doc.qt.io/qt/qtcore-index.html): Core non-GUI
  functionality including containers, threading, and file I/O.
- [Qt GUI Module](https://doc.qt.io/qt/qtgui-index.html): Base classes for GUI
  components, events, and graphics.
- [Qt Widgets Module](https://doc.qt.io/qt/qtwidgets-index.html): C++ widget
  classes for desktop-style user interfaces.
- [Qt Quick Module](https://doc.qt.io/qt/qtquick-index.html): Declarative
  framework for building fluid, animated user interfaces.
- [Qt QML Module](https://doc.qt.io/qt/qtqml-index.html): QML language and
  JavaScript runtime environment.
