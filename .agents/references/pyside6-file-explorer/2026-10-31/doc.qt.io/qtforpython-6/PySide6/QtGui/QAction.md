## Detailed Description[¶](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#detailed-description)

In applications many common commands can be invoked via menus, toolbar buttons, and keyboard shortcuts. Since the user expects each command to be performed in the same way, regardless of the user interface used, it is useful to represent each command as an action .

Actions can be added to user interface elements such as menus and toolbars, and will automatically keep the UI in sync. For example, in a word processor, if the user presses a Bold toolbar button, the Bold menu item will automatically be checked.

A ``[QAction](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction)  may contain an icon, descriptive text, icon text, a keyboard shortcut, status text, “What’s This?” text, and a tooltip. All properties can be set independently with ``[setIcon()](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.setIcon)  , ``[setText()](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.setText)  , ``[setIconText()](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.setIconText)  , ``[setShortcut()](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.setShortcut)  , ``[setStatusTip()](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.setStatusTip)  , ``[setWhatsThis()](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.setWhatsThis)  , and ``[setToolTip()](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.setToolTip)  . Icon and text, as the two most important properties, can also be set in the constructor. It’s possible to set an individual font with ``[setFont()](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.setFont)  , which e.g. menus respect when displaying the action as a menu item.

We recommend that actions are created as children of the window they are used in. In most cases actions will be children of the application’s main window.

> 

### QAction in widget applications[¶](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#qaction-in-widget-applications)

Once a ``[QAction](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction)  has been created, it should be added to the relevant menu and toolbar, then connected to the slot which will perform the action.

Actions are added to widgets using QWidget::addAction() or QGraphicsWidget::addAction(). Note that an action must be added to a widget before it can be used. This is also true when the shortcut should be global (i.e., Qt::ApplicationShortcut as Qt::ShortcutContext).

Actions can be created as independent objects. But they may also be created during the construction of menus. The QMenu class contains convenience functions for creating actions suitable for use as menu items.

property checkableᅟ : bool[¶](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.checkable)

This property holds whether the action is a checkable action.

A checkable action is one which has an on/off state. For example, in a word processor, a Bold toolbar button may be either on or off. An action which is not a toggle action is a command action; a command action is simply executed, e.g. file save. By default, this property is `false`.

In some situations, the state of one toggle action should depend on the state of others. For example, “Left Align”, “Center” and “Right Align” toggle actions are mutually exclusive. To achieve exclusive toggling, add the relevant toggle actions to a ``[QActionGroup](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QActionGroup.html#PySide6.QtGui.QActionGroup)  with the QActionGroup::exclusive property set to true.

property enabledᅟ : bool[¶](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.enabled)

This property holds whether the action is enabled.

Disabled actions cannot be chosen by the user. They do not disappear from menus or toolbars, but they are displayed in a way which indicates that they are unavailable. For example, they might be displayed using only shades of gray.

What’s This? help on disabled actions is still available, provided that the ``[whatsThis()](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#id11)  property is set.

toggled (checked )[¶](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.toggled) Parameters :

checked  – bool

This signal is emitted whenever a checkable action changes its ``[isChecked()](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.isChecked)  status. This can be the result of a user interaction, or because ``[setChecked()](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.setChecked)  was called. As ``[setChecked()](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.setChecked)  changes the ``[QAction](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction)  , it emits ``[changed()](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.changed)  in addition to toggled().

triggered ([checked=false ] )[¶](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.triggered) Parameters :

checked  – bool

This signal is emitted when an action is activated by the user; for example, when the user clicks a menu option, toolbar button, or presses an action’s shortcut key combination, or when ``[trigger()](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.trigger)  was called. Notably, it is not  emitted when ``[setChecked()](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.setChecked)  or ``[toggle()](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QAction.html#PySide6.QtGui.QAction.toggle)  is called.

If the action is checkable, `checked` is true if the action is checked, or false if the action is unchecked.
