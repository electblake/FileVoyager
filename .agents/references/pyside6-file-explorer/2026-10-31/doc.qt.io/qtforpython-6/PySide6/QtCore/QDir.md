## Detailed Description[¶](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#detailed-description)

Warning

This section contains snippets that were automatically translated from C++ to Python and may contain errors.

A ``[QDir](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir)  is used to manipulate path names, access information regarding paths and files, and manipulate the underlying file system. It can also be used to access Qt’s [resource system](https://doc.qt.io/qtforpython-6/overviews/qtcore-resources.html#the-qt-resource-system)  .

Qt uses “/” as a universal directory separator in the same way that “/” is used as a path separator in URLs. If you always use “/” as a directory separator, Qt will translate your paths to conform to the underlying operating system.

A ``[QDir](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir)  can point to a file using either a relative or an absolute path. Absolute paths begin with the directory separator (optionally preceded by a drive specification under Windows). Relative file names begin with a directory name or a file name and specify a path relative to the current directory.

Examples of absolute paths:

> 

```
QDir("/home/user/Documents")
QDir("C:/Users")
```

On Windows, the second example above will be translated to `C:\Users` when used to access files.

Examples of relative paths:

> 

```
QDir("images/landscape.png")
```

You can use the ``[isRelative()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.isRelative)  or ``[isAbsolute()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.isAbsolute)  functions to check if a ``[QDir](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir)  is using a relative or an absolute file path. Call ``[makeAbsolute()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.makeAbsolute)  to convert a relative ``[QDir](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir)  to an absolute one.

Note

Paths starting with a colon (: ) are always considered absolute, as they denote a ``[QResource](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QResource.html#PySide6.QtCore.QResource)  .

### Navigation and Directory Operations[¶](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#navigation-and-directory-operations)

A directory’s path can be obtained with the ``[path()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.path)  function, and a new path set with the ``[setPath()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.setPath)  function. The absolute path to a directory is found by calling ``[absolutePath()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.absolutePath)  .

The name of a directory is found using the ``[dirName()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.dirName)  function. This typically returns the last element in the absolute path that specifies the location of the directory. However, it can also return “.” if the ``[QDir](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir)  represents the current directory.

> 

```
QDir("Documents/Letters/Applications").dirName() # "Applications"
QDir().dirName() # "."
```

The path for a directory can also be changed with the ``[cd()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.cd)  and ``[cdUp()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.cdUp)  functions, both of which operate like familiar shell commands. When ``[cd()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.cd)  is called with the name of an existing directory, the ``[QDir](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir)  object changes directory so that it represents that directory instead. The ``[cdUp()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.cdUp)  function changes the directory of the ``[QDir](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir)  object so that it refers to its parent directory; i.e. cd(“..”) is equivalent to ``[cdUp()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.cdUp)  .

Directories can be created with ``[mkdir()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.mkdir)  , renamed with ``[rename()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.rename)  , and removed with ``[rmdir()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.rmdir)  .

You can test for the presence of a directory with a given name by using ``[exists()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.exists)  , and the properties of a directory can be tested with ``[isReadable()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.isReadable)  , ``[isAbsolute()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.isAbsolute)  , ``[isRelative()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.isRelative)  , and ``[isRoot()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.isRoot)  .

The ``[refresh()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.refresh)  function re-reads the directory’s data from disk.

> 

### Files and Directory Contents[¶](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#files-and-directory-contents)

Directories contain a number of entries, representing files, directories, and symbolic links. The number of entries in a directory is returned by ``[count()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.count)  . A string list of the names of all the entries in a directory can be obtained with ``[entryList()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.entryList)  . If you need information about each entry, use ``[entryInfoList()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.entryInfoList)  to obtain a list of ``[QFileInfo](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QFileInfo.html#PySide6.QtCore.QFileInfo)  objects.

Paths to files and directories within a directory can be constructed using ``[filePath()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.filePath)  and ``[absoluteFilePath()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.absoluteFilePath)  . The ``[filePath()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.filePath)  function returns a path to the specified file or directory relative to the path of the ``[QDir](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir)  object; ``[absoluteFilePath()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.absoluteFilePath)  returns an absolute path to the specified file or directory. Neither of these functions checks for the existence of files or directory; they only construct paths.

> 

```
directory = QDir("Documents/Letters")
path = directory.filePath("contents.txt")
absolutePath = directory.absoluteFilePath("contents.txt")
```

Files can be removed by using the ``[remove()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.remove)  function. Directories cannot be removed in the same way as files; use ``[rmdir()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.rmdir)  to remove them instead.

It is possible to reduce the number of entries returned by ``[entryList()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.entryList)  and ``[entryInfoList()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.entryInfoList)  by applying filters to a ``[QDir](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir)  object. You can apply a name filter to specify a pattern with wildcards that file names need to match, an attribute filter that selects properties of entries and can distinguish between files and directories, and a sort order.

Name filters are lists of strings that are passed to ``[setNameFilters()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.setNameFilters)  . Attribute filters consist of a bitwise OR combination of Filters, and these are specified when calling ``[setFilter()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.setFilter)  . The sort order is specified using ``[setSorting()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.setSorting)  with a bitwise OR combination of `SortFlags` .

You can test to see if a filename matches a filter using the ``[match()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.match)  function.

Filter and sort order flags may also be specified when calling ``[entryList()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.entryList)  and ``[entryInfoList()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.entryInfoList)  in order to override previously defined behavior.

### Path Manipulation and Strings[¶](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#path-manipulation-and-strings)

Paths containing “.” elements that reference the current directory at that point in the path, “..” elements that reference the parent directory, and symbolic links can be reduced to a canonical form using the ``[canonicalPath()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.canonicalPath)  function.

Paths can also be simplified by using ``[cleanPath()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.cleanPath)  to remove redundant “/” and “..” elements.

It is sometimes necessary to be able to show a path in the native representation for the user’s platform. The static ``[toNativeSeparators()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.toNativeSeparators)  function returns a copy of the specified path in which each directory separator is replaced by the appropriate separator for the underlying operating system.

class Filter[¶](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.Filter)

(inherits `enum.Flag`) This enum describes the filtering options available to ``[QDir](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir)  ; e.g. for ``[entryList()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.entryList)  and ``[entryInfoList()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.entryInfoList)  . The filter value is specified by combining values from the following list using the bitwise OR operator:

> 

Constant

Description

QDir.Filter.Dirs

List directories that match the filters.

QDir.Filter.AllDirs

List all directories; i.e. don’t apply the filters to directory names.

QDir.Filter.Files

List files.

QDir.Filter.Drives

List disk drives (ignored under Unix).

QDir.Filter.NoSymLinks

Do not list symbolic links (ignored by operating systems that don’t support symbolic links).

QDir.Filter.NoDotAndDotDot

Do not list the special entries “.” and “..”.

QDir.Filter.NoDot

Do not list the special entry “.”.

QDir.Filter.NoDotDot

Do not list the special entry “..”.

QDir.Filter.AllEntries

List directories, files, drives and symlinks (this does not list broken symlinks unless you specify System).

QDir.Filter.Readable

List files for which the application has read access. The Readable value needs to be combined with Dirs or Files.

QDir.Filter.Writable

List files for which the application has write access. The Writable value needs to be combined with Dirs or Files.

QDir.Filter.Executable

List files for which the application has execute access. The Executable value needs to be combined with Dirs or Files.

This makes the default easy to write, and at the same time useful.

For example, setting the `Readable`, `Writable`, and `Files` flags allows all files to be listed for which the application has read access, write access or both. If the `Dirs` and `Drives` flags are also included in this combination then all drives, directories, all files that the application can read, write, or execute, and symlinks to such files/directories can be listed.

To retrieve the permissions for a directory, use the ``[entryInfoList()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QDir.html#PySide6.QtCore.QDir.entryInfoList)  function to get the associated ``[QFileInfo](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QFileInfo.html#PySide6.QtCore.QFileInfo)  objects and then use the ``[permissions()](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QFileInfo.html#PySide6.QtCore.QFileInfo.permissions)  to obtain the permissions and ownership for each file.

Sets or replaces Qt’s search paths for file names with the prefix `prefix` to `searchPaths`.

To specify a prefix for a file name, prepend the prefix followed by a single colon (e.g., “images:undo.png”, “xmldocs:books.xml”). `prefix` can only contain letters or numbers (e.g., it cannot contain a colon, nor a slash).

Qt uses this search path to locate files with a known prefix. The search path entries are tested in order, starting with the first entry.

> 

```
    QDir.setSearchPaths("icons", QStringList(QDir.homePath() + "/images"))
    QDir.setSearchPaths("docs", QStringList(":/embeddedDocuments"))
#...
    QPixmap pixmap("icons:undo.png") # will look for undo.png in QDir.homePath() + "/images"
    QFile file("docs:design.odf") # will look in the :/embeddedDocuments resource path
```

File name prefix must be at least 2 characters long to avoid conflicts with Windows drive letters.

Search paths may contain paths to [The Qt Resource System](https://doc.qt.io/qtforpython-6/overviews/qtcore-resources.html#the-qt-resource-system)  .
