## Detailed Description[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#detailed-description)

> 

A line edit allows users to enter and edit a single line of plain text with useful editing functions, including undo and redo, cut and paste, and drag and drop.

By changing the ``[echoMode()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#id5)  of a line edit, it can also be used as a write-only field for inputs such as passwords.

``[QTextEdit](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QTextEdit.html#PySide6.QtWidgets.QTextEdit)  is a related class that allows multi-line, rich text editing.

> 

### Constraining Text[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#constraining-text)

Use ``[maxLength()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#id8)  to define the maximum permitted length of a text. You can use a ``[inputMask()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#id7)  and ``[setValidator()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.setValidator)  to further constrain the text content.

> 

### Editing Text[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#editing-text)

You can change the text with ``[setText()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.setText)  or ``[insert()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.insert)  . Use ``[text()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#id11)  to retrieve the text and ``[displayText()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#id3)  to retrieve the displayed text (which may be different, see ``[EchoMode](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.EchoMode)  ). You can select the text with ``[setSelection()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.setSelection)  or ``[selectAll()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.selectAll)  , and you can ``[cut()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.cut)  , ``[copy()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.copy)  , and ``[paste()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.paste)  the selection. To align the text, use ``[setAlignment()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.setAlignment)  .

When the text changes, the ``[textChanged()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.textChanged)  signal is emitted. When the text changes in some other way than by calling ``[setText()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.setText)  , the ``[textEdited()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.textEdited)  signal is emitted. When the cursor is moved, the ``[cursorPositionChanged()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.cursorPositionChanged)  signal is emitted. And when the Return or Enter key is selected, the ``[returnPressed()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.returnPressed)  signal is emitted.

When text editing is finished, either because the line edit lost focus or Return/Enter was selected, the ``[editingFinished()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.editingFinished)  signal is emitted.

If the line edit focus is lost without any text changes, the ``[editingFinished()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.editingFinished)  signal won’t be emitted.

If there is a validator set on the line edit, the ``[returnPressed()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.returnPressed)  / ``[editingFinished()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.editingFinished)  signals will only be emitted if the validator returns QValidator::Acceptable.

For more information on the many ways that ``[QLineEdit](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit)  can be used, see Line-Edits-Example  , which also provides a selection of line edit examples that show the effects of various properties and validators on the input and output supplied by the user.

> 

### Setting a Frame[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#setting-a-frame)

By default, QLineEdits have a frame as specified in the platform style guides. You can turn the frame off by calling ``[setFrame()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.setFrame)  (false).

> 

### Default Key Bindings[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#default-key-bindings)

The table below describes the default key bindings.

Note

The line edit also provides a context menu (usually invoked by a right-click) that presents some of the editing options listed below.

> 

Keystroke

Action

Left Arrow

Moves the cursor one character to the left.

Shift+Left Arrow

Moves and selects text one character to the left.

Right Arrow

Moves the cursor one character to the right.

Shift+Right Arrow

Moves and selects text one character to the right.

Home

Moves the cursor to the beginning of the line.

End

Moves the cursor to the end of the line.

Backspace

Deletes the character to the left of the cursor.

Ctrl+Backspace

Deletes the word to the left of the cursor.

Delete

Deletes the character to the right of the cursor.

Ctrl+Delete

Deletes the word to the right of the cursor.

Ctrl+A

property inputMaskᅟ : str[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.inputMask)

This property holds The validation input mask..

Sets the ``[QLineEdit](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit)  ‘s validation mask. Validators can be used instead of, or in conjunction with masks; see ``[setValidator()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.setValidator)  . The default is an empty string, which means that no input mask is used.

To unset the mask and return to normal ``[QLineEdit](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit)  operation, pass an empty string.

The input mask is an input template string. It can contain the following elements:

> 

Mask Characters

Defines the Category of input characters that are considered valid in this position.

Meta Characters

Various special meanings (see details below).

Separators

All other characters are regarded as immutable separators.

The following table shows the mask and meta characters that can be used in an input mask.

> 

Mask Character

Meaning

`A`

Character of the Letter category required, such as A-Z, a-z.

`a`

Character of the Letter category permitted but not required.

`N`

Character of the Letter or Number category required, such as A-Z, a-z, 0-9.

`n`

Character of the Letter or Number category permitted but not required.

`X`

Any non-blank character required.

`x`

Any non-blank character permitted but not required.

`9`

Character of the Number category required, such as 0-9.

`0`

Character of the Number category permitted but not required.

`D`

Character of the Number category and larger than zero required, such as 1-9.

`d`

Character of the Number category and larger than zero permitted but not required, such as 1-9.

`#`

Character of the Number category, or plus/minus sign permitted but not required.

`H`

Hexadecimal character required. A-F, a-f, 0-9.

`h`

Hexadecimal character permitted but not required.

`B`

Binary character required. 0-1.

`b`

Binary character permitted but not required.

Meta Character

Meaning

`>`

All following alphabetic characters are uppercased.

`<`

All following alphabetic characters are lowercased.

`!`

Switch off case conversion.

`;c`

Terminates the input mask and sets the blank  character to c .

`[] { }`

Reserved.

`\`

Use `\` to escape the special characters listed above to use them as separators.

When created or cleared, the line edit will be filled with a copy of the input mask string where the meta characters have been removed, and the mask characters have been replaced with the blank  character (by default, a `space`).

When an input mask is set, the ``[text()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#id11)  method returns a modified copy of the line edit content where all the blank  characters have been removed. The unmodified content can be read using ``[displayText()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#id3)  .

The ``[hasAcceptableInput()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.hasAcceptableInput)  method returns false if the current content of the line edit does not fulfill the requirements of the input mask.

Examples:

> 

Mask

Notes

`000.000.000.000;_`

IP address; blanks are `_`.

`HH:HH:HH:HH:HH:HH;_`

MAC address

`0000-00-00`

ISO Date; blanks are `space`

`>AAAAA-AAAAA-AAAAA-AAAAA-AAAAA;#`

License number; blanks are `#` and all (alphabetic) characters are converted to uppercase.

To get range control (e.g., for an IP address) use masks together with ``[validators](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.setValidator)  .

setValidator (v )[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.setValidator) Parameters :

v  – ``[QValidator](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QValidator.html#PySide6.QtGui.QValidator)

Sets the validator for values of line edit to `v`.

The line edit’s ``[returnPressed()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.returnPressed)  and ``[editingFinished()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#PySide6.QtWidgets.QLineEdit.editingFinished)  signals will only be emitted if `v` validates the line edit’s content as Acceptable. The user may change the content to any Intermediate value during editing, but will be prevented from editing the text to a value that `v` validates as Invalid.

This allows you to constrain the text that will be stored when editing is done while leaving users with enough freedom to edit the text from one valid state to another.

To remove the current input validator, pass `nullptr`. The initial setting is to have no input validator (any input is accepted up to ``[maxLength()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLineEdit.html#id8)  ).
