## Detailed Description[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#detailed-description)

> 

A ``[QListView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView)  presents items stored in a model, either as a simple non-hierarchical list, or as a collection of icons. This class is used to provide lists and icon views that were previously provided by the `QListBox` and `QIconView` classes, but using the more flexible approach provided by Qt’s model/view architecture.

The ``[QListView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView)  class is one of the [Model/View Classes](https://doc.qt.io/qtforpython-6/overviews/qtwidgets-model-view-programming.html#model-view-programming)  and is part of Qt’s [model/view framework](https://doc.qt.io/qtforpython-6/overviews/qtwidgets-model-view-programming.html#model-view-programming)  .

This view does not display horizontal or vertical headers; to display a list of items with a horizontal header, use ``[QTreeView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QTreeView.html#PySide6.QtWidgets.QTreeView)  instead.

``[QListView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView)  implements the interfaces defined by the ``[QAbstractItemView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QAbstractItemView.html#PySide6.QtWidgets.QAbstractItemView)  class to allow it to display data provided by models derived from the QAbstractItemModel class.

Items in a list view can be displayed using one of two view modes: In ``[ListMode](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView.ViewMode)  , the items are displayed in the form of a simple list; in ``[IconMode](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView.ViewMode)  , the list view takes the form of an icon view  in which the items are displayed with icons like files in a file manager. By default, the list view is in ``[ListMode](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView.ViewMode)  . To change the view mode, use the ``[setViewMode()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView.setViewMode)  function, and to determine the current view mode, use ``[viewMode()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#id11)  .

Items in these views are laid out in the direction specified by the ``[flow()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#id1)  of the list view. The items may be fixed in place, or allowed to move, depending on the view’s ``[movement()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#id7)  state.

If the items in the model cannot be completely laid out in the direction of flow, they can be wrapped at the boundary of the view widget; this depends on ``[isWrapping()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#id3)  . This property is useful when the items are being represented by an icon view.

The ``[resizeMode()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#id8)  and ``[layoutMode()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#id5)  govern how and when the items are laid out. Items are spaced according to their ``[spacing()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#id9)  , and can exist within a notional grid of size specified by ``[gridSize()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#id2)  . The items can be rendered as large or small icons depending on their `iconSize()` .

> 

### Improving Performance[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#improving-performance)

It is possible to give the view hints about the data it is handling in order to improve its performance when displaying large numbers of items. One approach that can be taken for views that are intended to display items with equal sizes is to set the ``[uniformItemSizes()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#id10)  property to true.

property flowᅟ :[QListView.Flow](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView.Flow)[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView.flow)

This property holds which direction the items layout should flow..

If this property is ``[LeftToRight](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView.Flow)  , the items will be laid out left to right. If the ``[isWrapping()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#id3)  property is `true`, the layout will wrap when it reaches the right side of the visible area. If this property is ``[TopToBottom](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView.Flow)  , the items will be laid out from the top of the visible area, wrapping when it reaches the bottom.

Setting this property when the view is visible will cause the items to be laid out again.

By default, this property is set to ``[TopToBottom](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView.Flow)  .

property layoutModeᅟ :[QListView.LayoutMode](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView.LayoutMode)[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView.layoutMode)

This property determines whether the layout of items should happen immediately or be delayed..

This property holds the layout mode for the items. When the mode is ``[SinglePass](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView.LayoutMode)  (the default), the items are laid out all in one go. When the mode is ``[Batched](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView.LayoutMode)  , the items are laid out in batches of ``[batchSize()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#id0)  items, while processing events. This makes it possible to instantly view and interact with the visible items while the rest are being laid out.
