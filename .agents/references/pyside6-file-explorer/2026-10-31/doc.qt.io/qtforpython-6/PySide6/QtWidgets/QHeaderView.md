## Detailed Description[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#detailed-description)

A ``[QHeaderView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView)  displays the headers used in item views such as the ``[QTableView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QTableView.html#PySide6.QtWidgets.QTableView)  and ``[QTreeView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QTreeView.html#PySide6.QtWidgets.QTreeView)  classes. It takes the place of Qt3’s `QHeader` class previously used for the same purpose, but uses the Qt’s model/view architecture for consistency with the item view classes.

The ``[QHeaderView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView)  class is one of the [Model/View Classes](https://doc.qt.io/qtforpython-6/overviews/qtwidgets-model-view-programming.html#model-view-programming)  and is part of Qt’s [model/view framework](https://doc.qt.io/qtforpython-6/overviews/qtwidgets-model-view-programming.html#model-view-programming)  .

The header gets the data for each section from the model using the QAbstractItemModel::headerData() function. You can set the data by using QAbstractItemModel::setHeaderData().

Each header has an ``[orientation()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.orientation)  and a number of sections, given by the ``[count()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.count)  function. A section refers to a part of the header - either a row or a column, depending on the orientation.

Sections can be moved and resized using ``[moveSection()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.moveSection)  and ``[resizeSection()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.resizeSection)  ; they can also be hidden and shown with ``[hideSection()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.hideSection)  and ``[showSection()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.showSection)  .

Each section of a header is described by a section ID, specified by its section(), and can be located at a particular ``[visualIndex()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.visualIndex)  in the header. A section can have a sort indicator set with ``[setSortIndicator()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.setSortIndicator)  ; this indicates whether the items in the associated item view will be sorted in the order given by the section.

For a horizontal header the section is equivalent to a column in the model, and for a vertical header the section is equivalent to a row in the model.

> 

### Moving Header Sections[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#moving-header-sections)

A header can be fixed in place, or made movable with ``[setSectionsMovable()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.setSectionsMovable)  . It can be made clickable with ``[setSectionsClickable()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.setSectionsClickable)  , and has resizing behavior in accordance with ``[setSectionResizeMode()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.setSectionResizeMode)  .

Note

Double-clicking on a header to resize a section only applies for visible rows.

A header will emit ``[sectionMoved()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.sectionMoved)  if the user moves a section, ``[sectionResized()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.sectionResized)  if the user resizes a section, and ``[sectionClicked()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.sectionClicked)  as well as ``[sectionHandleDoubleClicked()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.sectionHandleDoubleClicked)  in response to mouse clicks. A header will also emit ``[sectionCountChanged()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.sectionCountChanged)  .

You can identify a section using the ``[logicalIndex()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.logicalIndex)  and ``[logicalIndexAt()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.logicalIndexAt)  functions, or by its index position, using the ``[visualIndex()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.visualIndex)  and ``[visualIndexAt()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.visualIndexAt)  functions. The visual index will change if a section is moved, but the logical index will not change.

> 

### Appearance[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#appearance)

``[QTableWidget](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QTableWidget.html#PySide6.QtWidgets.QTableWidget)  and ``[QTableView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QTableView.html#PySide6.QtWidgets.QTableView)  create default headers. If you want the headers to be visible, you can use `setVisible()` .

Not all ItemDataRoles will have an effect on a ``[QHeaderView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView)  . If you need to draw other roles, you can subclass ``[QHeaderView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView)  and reimplement `paintEvent()` . ``[QHeaderView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView)  respects the following item data roles, unless they are in conflict with the style (which can happen for styles that follow the desktop theme):

TextAlignmentRole, DisplayRole, FontRole, DecorationRole, ForegroundRole, and BackgroundRole.

Note

Each header renders the data for each section itself, and does not rely on a delegate. As a result, calling a header’s `setItemDelegate()` function will have no effect.

### Special consideration for huge models[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#special-consideration-for-huge-models)

The headerview uses 8 to 16 bytes of memory per section. However, since Qt 6.9 this section memory is only used if one or more sections are resized or reordered. This means that it’s possible for a model to have millions of sections without ``[QHeaderView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView)  consuming a proportional, and therefore huge, amount of memory, as long as there are no  calls to ``[swapSections()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.swapSections)  , ``[resizeSection()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.resizeSection)  , ``[hideSection()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.hideSection)  , ``[moveSection()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.moveSection)  , and ``[stretchLastSection()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#id8)  (enabling it). In order to avoid such calls by user actions the ``[resize mode](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.sectionResizeMode)  should be ``[Fixed](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.ResizeMode)  (without specifying it for any indexes, as that will do the opposite). The user should also be prevented from moving sections by keeping ``[sectionsMovable()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#id7)  disabled.

> 

### Security Considerations[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#security-considerations)

The ``[restoreState()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.restoreState)  function deserializes a versioned binary blob that describes column order, section sizes, the sort indicator, and related view state. The format’s magic number, version, and reported total length are validated, but the deserialized visual and logical indices and the sort indicator’s section are not checked against the header’s actual section count before being used to index internal data structures.

Only pass ``[restoreState()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.restoreState)  a QByteArray that was previously produced by ``[saveState()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.saveState)  and persisted by the same, or a compatible, version of your application, typically round-tripped through QSettings. Do not call ``[restoreState()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.restoreState)  with data of unknown or untrusted origin, such as a file downloaded from the network, a synced or shared configuration file, or data supplied by another, potentially compromised, application.

class ResizeMode[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.ResizeMode)

The resize mode specifies the behavior of the header sections. It can be set on the entire header view or on individual sections using ``[setSectionResizeMode()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.setSectionResizeMode)  .

> 

Constant

Description

QHeaderView.ResizeMode.Interactive

The user can resize the section. The section can also be resized programmatically using ``[resizeSection()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.resizeSection)  . The section size defaults to ``[defaultSectionSize()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#id2)  . (See also ``[cascadingSectionResizes()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#id0)  .)

QHeaderView.ResizeMode.Fixed

The user cannot resize the section. The section can only be resized programmatically using ``[resizeSection()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.resizeSection)  . The section size defaults to ``[defaultSectionSize()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#id2)  .

QHeaderView.ResizeMode.Stretch

``[QHeaderView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView)  will automatically resize the section to fill the available space. The size cannot be changed by the user or programmatically.

QHeaderView.ResizeMode.ResizeToContents

``[QHeaderView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView)  will automatically resize the section to its optimal size based on the contents of the entire column or row. The size cannot be changed by the user or programmatically. (This value was introduced in 4.2)

setResizeContentsPrecision (precision )[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.setResizeContentsPrecision) Parameters :

precision  – int

Sets how precise ``[QHeaderView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView)  should calculate the size when ``[ResizeToContents](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QHeaderView.html#PySide6.QtWidgets.QHeaderView.ResizeMode)  is used. A low value will provide a less accurate but fast auto resize while a higher value will provide a more accurate resize that however can be slow.

The number `precision` specifies how many sections that should be consider when calculating the preferred size.

The default value is 1000 meaning that a horizontal column with auto-resize will look at maximum 1000 rows on calculating when doing an auto resize.

Special value 0 means that it will look at only the visible area. Special value -1 will imply looking at all elements.

This value is used in `sizeHintForColumn()` , `sizeHintForRow()` and `sizeHintForColumn()` . Reimplementing these functions can make this function not having an effect.
