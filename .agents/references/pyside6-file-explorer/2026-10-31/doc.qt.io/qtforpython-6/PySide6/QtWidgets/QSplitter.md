## Detailed Description[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#detailed-description)

Warning

This section contains snippets that were automatically translated from C++ to Python and may contain errors.

A splitter lets the user control the size of child widgets by dragging the boundary between them. Any number of widgets may be controlled by a single splitter. The typical use of a ``[QSplitter](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter)  is to create several widgets and add them using ``[insertWidget()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.insertWidget)  or ``[addWidget()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.addWidget)  .

The following example will show a ``[QListView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QListView.html#PySide6.QtWidgets.QListView)  , ``[QTreeView](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QTreeView.html#PySide6.QtWidgets.QTreeView)  , and ``[QTextEdit](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QTextEdit.html#PySide6.QtWidgets.QTextEdit)  side by side, with two splitter handles:

> 

```
splitter = QSplitter(parent)
listview = QListView()
treeview = QTreeView()
textedit = QTextEdit()
splitter.addWidget(listview)
splitter.addWidget(treeview)
splitter.addWidget(textedit)
```

If a widget is already inside a ``[QSplitter](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter)  when ``[insertWidget()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.insertWidget)  or ``[addWidget()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.addWidget)  is called, it will move to the new position. This can be used to reorder widgets in the splitter later. You can use ``[indexOf()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.indexOf)  , ``[widget()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.widget)  , and ``[count()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.count)  to get access to the widgets inside the splitter.

A default ``[QSplitter](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter)  lays out its children horizontally (side by side); you can use ``[setOrientation()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.setOrientation)  (Qt::Vertical) to lay its children out vertically.

By default, all widgets can be as large or as small as the user wishes, between the `minimumSizeHint()` (or `minimumSize()` ) and `maximumSize()` of the widgets.

``[QSplitter](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter)  resizes its children dynamically by default. If you would rather have ``[QSplitter](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter)  resize the children only at the end of a resize operation, call ``[setOpaqueResize()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.setOpaqueResize)  (false).

The initial distribution of size between the widgets is determined by multiplying the initial size with the stretch factor. You can also use ``[setSizes()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.setSizes)  to set the sizes of all the widgets. The function ``[sizes()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.sizes)  returns the sizes set by the user. Alternatively, you can save and restore the sizes of the widgets from a QByteArray using ``[saveState()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.saveState)  and ``[restoreState()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.restoreState)  respectively.

When you `hide()` a child, its space will be distributed among the other children. It will be reinstated when you `show()` it again.

Note

Adding a ``[QLayout](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLayout.html#PySide6.QtWidgets.QLayout)  to a ``[QSplitter](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter)  is not supported (either through `setLayout()` or making the ``[QSplitter](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter)  a parent of the ``[QLayout](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QLayout.html#PySide6.QtWidgets.QLayout)  ); use ``[addWidget()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.addWidget)  instead (see example above).

### Security Considerations[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#security-considerations)

The ``[restoreState()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.restoreState)  function deserializes a versioned binary blob that describes the sizes and orientation of the splitter’s children. The format’s magic number and version are validated, but the individual fields are not otherwise sanity-checked once the outer structure is accepted.

Only pass ``[restoreState()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.restoreState)  a QByteArray that was previously produced by ``[saveState()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.saveState)  and persisted by the same, or a compatible, version of your application, typically through QSettings. Do not call ``[restoreState()](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.restoreState)  with data of unknown or untrusted origin, such as a file downloaded from the network, a synced or shared configuration file, or data supplied by another, potentially compromised, application.

setSizes (list )[¶](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QSplitter.html#PySide6.QtWidgets.QSplitter.setSizes) Parameters :

list  – .list of int

Sets the child widgets’ respective sizes to the values given in the `list`.

If the splitter is horizontal, the values set the width of each widget in pixels, from left to right. If the splitter is vertical, the height of each widget is set, from top to bottom.

Extra values in the `list` are ignored. If `list` contains too few values, the result is undefined, but the program will still be well-behaved.

The overall size of the splitter widget is not affected. Instead, any additional/missing space is distributed amongst the widgets according to the relative weight of the sizes.

If you specify a size of 0, the widget will be invisible. The size policies of the widgets are preserved. That is, a value smaller than the minimal size hint of the respective widget will be replaced by the value of the hint.
