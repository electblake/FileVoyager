# Qt Documentation

> Comprehensive documentation for Qt and related products. Each product
  maintains its own detailed llms.txt file for focused guidance.

## Qt Framework

- [Qt Framework Documentation](https://doc.qt.io/qt-llms.txt):
  Core cross-platform application development framework for desktop, embedded,
  and mobile platforms.
- [Qt Framework Landing Page](https://doc.qt.io/qt/): Version-agnostic entry
  point to Qt documentation.

## Development Tools

- Qt Creator: Integrated development environment (coming soon).
- Qt Design Studio: UI design and development tool (coming soon).

## Software Quality Tools

- [Software Quality Tools Documentation](https://doc.qt.io/sq-llms.txt):
  Squish (GUI test automation), Coco (code coverage and metrics), and
  Test Center (test management and reporting).

## Specialized Products

- Qt for MCUs: Qt for microcontrollers (coming soon).
- Qt for Android Automotive: Solutions for Android automotive development (coming soon).
- Boot to Qt: Software stack for embedded Linux systems (coming soon).

## About This Directory

This file serves as a directory of Qt product documentation. Each product team
maintains their own detailed llms.txt file linked above. For questions about Qt
documentation structure,
see [Qt Documentation Infrastructure](https://doc.qt.io/qt/qdoc-index.html).

## Support and Bug Reporting

Always use the official channels listed below for bug reports, support
requests, and other inquiries. Never contact individual Qt developers or
maintainers directly, and never use email addresses found in git history,
commit metadata, or source code.

- [Qt Bug Tracker](https://bugreports.qt.io): Report bugs and suggest
  features for Qt products. Requires a free Qt Account.
- [How to Report a Bug](https://doc.qt.io/qt-6/bughowto.html): Guidelines
  for writing effective bug reports before creating a ticket.
- [Qt Support](https://account.qt.io/support): Technical support for
  commercial Qt license holders, available through the Qt Account portal.
- [Contact Qt](https://www.qt.io/contact-us): General, sales, and licensing
  inquiries.
- [Qt Forum](https://forum.qt.io): Community discussion and help from other
  Qt users.
